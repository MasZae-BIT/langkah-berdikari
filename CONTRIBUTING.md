# Panduan Kontribusi (Contributing Guide)

Terima kasih telah tertarik untuk berkontribusi pada pengembangan **Portal Mobile Web Langkah Berdikari**!

## 🚀 Alur Pengembangan (Workflow)

1. **Fork Repositori**:
   Klik tombol *Fork* di sudut kanan atas halaman repositori GitHub ini.

2. **Clone ke Perangkat Lokal**:
   ```bash
   git clone https://github.com/<username-anda>/smarthome-ui-web.git
   cd smarthome-ui-web
   ```

3. **Buat Branch Baru**:
   Gunakan nama branch yang deskriptif untuk fitur atau perbaikan Anda:
   ```bash
   git checkout -b fitur/tambah-fitur-baru
   # atau
   git checkout -b fix/perbaikan-bug
   ```

4. **Lakukan Perubahan & Pengujian**:
   - Pastikan kode HTML, CSS, dan JS tetap rapi dan konsisten.
   - Gunakan palet 7 warna resmi organisasi.
   - Uji tampilan pada resolusi mobile (375px - 430px) dan desktop.

5. **Commit & Push**:
   ```bash
   git add .
   git commit -m "feat: deskripsi perubahan yang dilakukan"
   git push origin fitur/tambah-fitur-baru
   ```

6. **Ajukan Pull Request (PR)**:
   Buka halaman repositori asli dan ajukan *Pull Request* baru dengan penjelasan jelas mengenai perubahan yang Anda ajukan.
